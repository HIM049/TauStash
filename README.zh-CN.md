# TauStash

[English](README.md) | 简体中文

按内容索引的文件库，一切皆标签。

## 为什么选择 TauStash？

文件夹系统强制每个文件只能待在一个位置。一张照片想同时归入多个分类，就只能复制多份。深层级或大量子目录也会导致归档难以浏览。

TauStash 换了一种思路。按内容索引文件，用标签来组织它们。合集由标签筛选动态生成，一个文件适合放进多少个合集，就能出现在多少个合集里。


## 功能

- **内容索引** — 通过文件指纹追踪文件，与设备和路径无关。
- **一切皆标签** — 状态和分类都是标签，可以任意组合筛选并重复使用。
- **动态合集** — 用标签筛选构建视图，视图随文件库的变化自动更新。
- **自动扫描** — 监听下载、图片等文件夹，导入新文件时自动打上预设标签。
- **存储库（可选）** — 将已归档的文件复制或移动到软件管理的存储库中。


## 工作方式

- **文件与副本** — 文件由其内容（哈希）识别。在多个位置发现的相同内容，是同一个文件的多个副本。
- **扫描源** — TauStash 扫描以发现并导入文件的文件夹。
- **标签** — 唯一的组织方式。归档、忽略和删除也是标签。
- **合集** — 保存下来的筛选条件，用于展示你需要的文件。文件夹和侧边栏视图都是合集。
- **存储库** — TauStash 可以将文件复制或移动进去的受管理文件夹。

> **注意：** 在 TauStash 中，删除是记录在文件内容上的一种状态。回收站保留期过后，如果同样的文件再次出现在任意扫描源中，会被自动删除。
